Web Development syllabus (8 weeks)

Beginner course with no prior coding needed. Every week ends with something built and pushed to GitHub.

Format2 live classes a week, 2 hours each
PracticeAbout 4 hours a week, with mentor feedback
Batch size15 to 25 students
Outcome4 portfolio projects and a live portfolio site

Week 1: Web basics and tools

How the web works, VS Code, Git and GitHub, HTML structure. Project: personal profile page.

Week 2: CSS and responsive layout

Selectors, spacing, Flexbox, Grid, mobile-first design. Project: responsive landing page for a business.

Week 3: JavaScript fundamentals

Variables, functions, arrays, objects, loops, logic. Project: quiz or calculator.

Week 4: JavaScript in the browser

DOM, events, forms, fetching data from APIs. Project: weather or currency app.

Week 5: React basics

Components, props, state, lists. Project: rebuild the Week 4 app in React.

Week 6: React in practice

Hooks, routing, working with API data, code organisation. Project: expense or task tracker.

Week 7: Deploy and polish

Hosting on Netlify or Vercel, accessibility, performance, reading client briefs. Project: live portfolio site.

Week 8: Capstone and freelance start

Build a small client-style project from a written brief, present it, then set up a first freelance profile. Project: capstone demo day.

Outreach messages

Send 10 personalised messages a day. Always mention something specific about the person's business, and never paste the same message twice.

1. LinkedIn connection note

Hi [Name], I saw [specific thing about their company]. I run Hunarstack, a small software team building web and AI tools for [industry] companies. Would be glad to connect.

2. First message after connecting

Thanks for connecting, [Name]. I noticed [specific observation, e.g. your booking page loads slowly on mobile]. We recently helped [similar client or demo project] with a similar issue. If useful, I can send a short list of fixes, free. No obligation.

3. Follow-up after 5 days

Hi [Name], following up in case my last note got buried. We take on fixed-price projects such as landing pages in 7 days or AI chatbots in 3 weeks. If [pain point] is on your list this quarter, happy to send a quote after a 15-minute call.

4. Student invitation (WhatsApp or DM)

Assalam o alaikum [Name]! We're starting the first batch of Hunarstack Academy's 8-week Web Development course. No coding experience needed, and you finish with 4 real projects. There's a free intro class on [date]. Want me to save you a seat?
