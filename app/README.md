# HunarStack product

React academy app: public catalogue plus student / instructor / admin logins.

## Run

```bash
cd app
npm install
npm run dev
```

Open the local URL Vite prints (usually http://localhost:5173).

## Demo accounts

| Role | Email | Password |
| --- | --- | --- |
| Student | student@hunarstack.com | student123 |
| Instructor | instructor@hunarstack.com | teach123 |
| Admin | admin@hunarstack.com | admin123 |

Data is stored in the browser (`localStorage`). It is a complete product flow without a server: register, apply, enrol, weekly progress, project submissions, freelance kit, reviews, users, applications, inbox.

HunarStack still does not guarantee clients, jobs or income.
